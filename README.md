# Markdown 렌더 테스트 세트 — 출처와 성격 (오해 방지)

> **먼저 읽을 것**: 이 폴더의 세트는 성격이 제각각이다. 특히 **L2 두 세트는 "정답이 검증된 큐레이션"이 아니라
> 공개 사이트에서 기계적으로 긁어 담은 원석(노이즈 포함)**이다. 개수(예: "수식 1,319개")를
> 커버리지·정답 수로 오해하지 말 것. 판정 방법은 세트마다 다르다(아래).
>
> 이 폴더(`.jira/…`)는 **git 미추적 로컬 스크래치**다. 재현이 필요하면 아래 출처에서 다시 수집한다.

## L2_math_katex — 주의

- **출처**: KaTeX 공식 사이트(`https://katex.org/`) 문서 페이지.
- **수집 방식**: 페이지의 달러 구간(`$…$`, `$$…$$`)을 **무차별 스캔해 추출**. 그래서 **진짜 수식이 아닌 것도 섞여 있다** —
  예: `katexdoc_0002.md`의 `$font-folder: "$`(문서 속 CSS 조각), `katexdoc_0001.md`의 설명 산문.
- **용도**: 수식 렌더 정확도 "정답 대조"가 아니라, **파서/`$` 델리미터 강건성 스트레스**(이상 입력에도 안 죽는지)에 적합.
  MOFF-12539(일반 `$` 오인)의 근거 소스이기도 하다.
- **오해 금지**: "1,319개 수식 지원"이 아니다. 유효 수식 + 스크레이프 노이즈가 섞인 원석이다.

## L2_mermaid — 주의

- **출처**: Mermaid 공식 문서(`https://mermaid.js.org/`), **8.6.0 스냅샷**(`mm_8.6.0_docs_*` 파일명이 버전 명시).
- **수집 방식**: 문서의 mermaid 코드블록을 **유형별로 총망라**(flowchart 114, sequence 38, class 38, gitgraph 35,
  block 30, ER 24, usecase 24, state 22, …). **의도적으로 미지원 신형 유형(mindmap/timeline/block/-beta 등)까지 포함**.
- **용도**: 유형 **커버리지 측정**(지원 305 / 대체 286, `../markdown-report.md` §4.4)과 플레이스홀더 동작 확인.
- **오해 금지**: "591개 도표 지원"이 아니다. 절반가량은 **미지원 유형(플레이스홀더로 대체)**이며, 이는 렌더 실패가 아니라 설계된 동작이다.
